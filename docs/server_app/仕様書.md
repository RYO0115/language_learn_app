# server_app API 仕様書

最終更新: 2026-07-27 / バージョン: 0.4.5

## 基本情報

- **ベース URL**: `http://0.0.0.0:8000`
- **レスポンス形式**: HTML（画面系） / HTML フラグメント（AJAX系）
- **認証**: なし
- **DB**: SQLite (`data/language_learn.db`)

## 単語管理 (`/words`)

### `GET /words`

単語一覧ページ。

**クエリパラメータ**

| パラメータ | 型 | デフォルト | 説明 |
|-----------|-----|-----------|------|
| `sort` | str | `created_at_desc` | ソート順 |
| `search` | str | `""` | フリーワード検索（前後の空白・ゼロ幅／不可視文字を正規化してから単語・意味に部分一致。正規化後に値があり結果が 0 件の場合は `/words/add?word=<正規化後の語>` へリダイレクト） |

**sort の値**

| 値 | 説明 |
|----|------|
| `created_at_desc` | 登録日降順（デフォルト） |
| `created_at_asc` | 登録日昇順 |
| `word_asc` | A-Z 順 |
| `word_desc` | Z-A 順 |
| `accuracy_asc` | 正解率昇順（未テスト含む） |

**レスポンス**: `words/list.html`

### `POST /words`

単語を新規作成。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `word` | ✓ | 単語 |
| `reading` | | IPA 読み |
| `meaning` | ✓ | 日本語意味 |
| `part_of_speech` | | 品詞 |
| `example_en_*` | | 英語例文（複数可） |
| `example_ja_*` | | 日本語訳（複数可） |
| `example_label_*` | | 例文ラベル（品詞等） |
| `source_type` | | `book`/`website`/`video`/`other` |
| `source_title` | | 出典タイトル |
| `source_url` | | URL |
| `source_page` | | ページ番号 |
| `source_detail` | | 詳細メモ |

**レスポンス**: 作成成功 → `/words/{id}` へリダイレクト / 重複 → エラー表示

> `word` は保存・重複判定の前に正規化される（前後の空白除去・連続空白の畳み込み・ゼロ幅／不可視文字の除去）。これにより iPhone 等が末尾に付与する空白・ゼロ幅文字の有無で同じ単語が重複登録されることを防ぐ。

## クイズ (`/quiz`)

クイズには2種類のタイプがある（`quiz_type`）。

| quiz_type | 概要 |
|-----------|------|
| `meaning`（デフォルト） | 単語を見て「覚えている/覚えていない」を自己判定する意味確認テスト |
| `fill_blank` | 例文中の対象単語を空欄にし、似ている単語2件を含む3択から正解を選ぶテスト。アンロック条件あり（仕様書「設計書.md」の「例文穴埋め3択テスト」参照） |

いずれも `quiz/session.html` を `phase` テンプレート変数で分岐してレンダリングする。

### `GET /quiz`

クイズ開始ページ。

**レスポンス**: `quiz/session.html`（`phase="start"`）

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `word_count` | int | 登録単語数 |
| `fill_blank_unlocked` | bool | 穴埋め3択テストがアンロックされているか |

---

### `POST /quiz/start`

クイズセッションを開始。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `quiz_type` | | `"meaning"`（デフォルト）または `"fill_blank"` |

**ビジネスロジック**:
1. `quiz_type` に応じた優先度ロジック・出題対象プールで `QUIZ_QUESTION_COUNT` 件の単語を選択
2. `QuizSession` 作成
3. `QuizSessionWord` を order 付きで一括作成（`fill_blank` の場合は例文・3択選択肢 `QuizSessionWordChoice` も同時生成）
4. 最初の問題へリダイレクト

出題可能な単語がない場合（`fill_blank` はアンロック条件未達の場合も含む）はエラーメッセージ付きで `phase="start"` を再表示する。

**レスポンス**: `/quiz/{session_id}` へリダイレクト

---

### `GET /quiz/{session_id}`

クイズ問題表示。全問回答済みの場合は結果ページへリダイレクトする。

**パスパラメータ**: `session_id` (int)

**レスポンス（`quiz_type == "meaning"`）**: `quiz/session.html`（`phase="question"`）

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `word` | Word | 現在の問題単語 |
| `current_num` / `total` | int | 進捗 |

**レスポンス（`quiz_type == "fill_blank"`）**: `quiz/session.html`（`phase="fill_blank_question"`）

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `session_word_id` | int | 回答送信時に必要な `QuizSessionWord` ID |
| `word` | Word | 出題単語（正解） |
| `sentence_en_blanked` | str | 対象単語を `_____` に置換した例文 |
| `choices` | list[dict] | `{"word_id": int, "text": str}` の3択（シャッフル済み） |
| `current_num` / `total` | int | 進捗 |

---

### `POST /quiz/{session_id}/answer`

回答を送信。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `quiz_type` | | `"meaning"`（デフォルト）または `"fill_blank"` |
| `word_id` | `meaning` のみ必須 | 回答した単語 ID |
| `is_correct` | `meaning` のみ必須 | `"true"` / `"false"`（自己判定） |
| `session_word_id` | `fill_blank` のみ必須 | 出題単語の `QuizSessionWord` ID |
| `selected_word_id` | `fill_blank` のみ必須 | 選択した単語 ID |

**ビジネスロジック（`meaning`）**:
- `QuizAnswer` を記録、`QuizSessionWord.is_answered = True`
- 全問終了時: `QuizSession.completed_at` 設定 + `StudyRecord` 更新

**レスポンス（`meaning`）**: 次の問題 or `/quiz/{session_id}/result` へリダイレクト

**ビジネスロジック（`fill_blank`）**:
- 選択した単語が正解選択肢と一致するか判定し `QuizAnswer` を記録、`QuizSessionWord.is_answered = True`
- 全問終了時: `QuizSession.completed_at` 設定 + `StudyRecord` 更新

**レスポンス（`fill_blank`）**: `quiz/session.html`（`phase="fill_blank_feedback"`、リダイレクトせずその場で返す）

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `is_correct` | bool | 正誤 |
| `is_completed` | bool | 全問終了したか（「次へ」/「結果を見る」の分岐に使用） |
| `sentence_en` / `sentence_ja` | str | 出題例文の英文・日本語訳 |
| `choices` | list[dict] | `{"word_id", "word", "meaning", "is_correct", "is_selected"}` |

---

### `GET /quiz/{session_id}/result`

クイズ結果ページ。

## AI 連携 (`/api/ai`)

AJAX エンドポイント。レスポンスは HTML フラグメント。

### `POST /api/ai/generate`

単語情報を AI で自動生成。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `word` | ✓ | 生成対象の単語 |

**レスポンス（成功時）**: `words/partials/ai_result.html` フラグメント（HTTP 200）

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `result` | AIGenerateResponse | 生成結果 |

**レスポンス（失敗時）**: `words/partials/ai_error.html` フラグメント

| ステータスコード | 状況 | テンプレート変数 |
|-----------------|------|-----------------|
| 429 | レート制限・クォータ超過 | `error`（メッセージ）, `retry_after_seconds`（再試行までの待機秒数、不明な場合あり） |
| 503 | AI サービスが一時的に利用不可（Gemini の overloaded / HTTP 503 UNAVAILABLE など） | `error`（メッセージ）, `retry_after_seconds`（再試行までの待機秒数、不明な場合あり） |
| 500 | その他の API 呼び出し失敗・レスポンス解析失敗 | `error`（メッセージ） |

---

### `POST /api/spell-check`

スペルチェック・重複チェック。`word` は判定前に正規化（前後の空白除去・ゼロ幅／不可視文字の除去）される。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `word` | ✓ | チェック対象の単語 |

**レスポンス**: `ai/spell_check_result.html` フラグメント

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `is_correct` | bool | スペルが正しいか |
| `suggestions` | list[str] | 修正候補 |
| `is_duplicate` | bool | 既存単語に重複があるか |

## インポート/エクスポート (`/export`)

### `GET /export/download/json`

全単語を JSON でダウンロード。

**レスポンス**: `Content-Disposition: attachment; filename="words_YYYYMMDD.json"`

**JSON 構造**:
```json
[
  {
    "word": "example",
    "reading": "/ɪɡˈzæmpəl/",
    "meaning": "例",
    "part_of_speech": "名詞",
    "example_sentences": [
      {"sentence_en": "...", "sentence_ja": "...", "order": 0, "label": null}
    ],
    "sources": [
      {"source_type": "book", "title": "...", "url": null, "page_number": null, "detail": null}
    ]
  }
]
```

---

### `GET /export/download/csv`

全単語を CSV でダウンロード。

**レスポンス**: `Content-Disposition: attachment; filename="words_YYYYMMDD.csv"`

**CSV カラム（13列）**:

| カラム名 | 説明 |
|---------|------|
| word | 単語 |
| reading | 読み |
| meaning | 意味 |
| part_of_speech | 品詞 |
| example_en_1 | 英語例文1 |
| example_ja_1 | 日本語訳1 |
| example_en_2 | 英語例文2 |
| example_ja_2 | 日本語訳2 |
| source_type | 出典種別 |
| source_title | 出典タイトル |
| source_url | URL |
| source_page | ページ番号 |
| source_detail | 詳細 |

---

### `POST /export/import`

ファイルから単語を一括インポート。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `file` | ✓ | `.json` または `.csv` ファイル |

**レスポンス**: `/settings` へリダイレクト（フラッシュメッセージ付き）

**インポート結果**:
- `imported`: 登録件数
- `skipped`: 重複スキップ件数
- `errors`: エラー件数
