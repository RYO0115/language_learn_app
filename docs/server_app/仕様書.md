# server_app API 仕様書

最終更新: 2026-06-19 / バージョン: 0.2.9

## 基本情報

- **ベース URL**: `http://0.0.0.0:8000`
- **レスポンス形式**: HTML（画面系） / HTML フラグメント（AJAX系）
- **認証**: なし
- **DB**: SQLite (`data/language_learn.db`)

---

## 単語管理 (`/words`)

### `GET /words`

単語一覧ページ。

**クエリパラメータ**

| パラメータ | 型 | デフォルト | 説明 |
|-----------|-----|-----------|------|
| `sort` | str | `created_at_desc` | ソート順 |
| `search` | str | `""` | フリーワード検索 |

**sort の値**

| 値 | 説明 |
|----|------|
| `created_at_desc` | 登録日降順（デフォルト） |
| `created_at_asc` | 登録日昇順 |
| `word_asc` | A-Z 順 |
| `word_desc` | Z-A 順 |
| `accuracy_asc` | 正解率昇順（未テスト含む） |

**レスポンス**: `words/list.html`

---

### `GET /words/add`

単語追加ページ。

**レスポンス**: `words/add.html`

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `source_suggestions` | list[str] | 既存ソースタイトルの候補 |

---

### `POST /words`

単語を新規作成。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `word` | ✓ | 単語 |
| `reading` | | IPA 読み |
| `meaning` | ✓ | 日本語意味 |
| `part_of_speech` | | 品詞 |
| `example_en_*` | | 英語例文（複数可） |
| `example_ja_*` | | 日本語訳（複数可） |
| `example_label_*` | | 例文ラベル（品詞等） |
| `source_type` | | `book`/`website`/`video`/`other` |
| `source_title` | | 出典タイトル |
| `source_url` | | URL |
| `source_page` | | ページ番号 |
| `source_detail` | | 詳細メモ |

**レスポンス**: 作成成功 → `/words/{id}` へリダイレクト / 重複 → エラー表示

---

### `GET /words/{word_id}`

単語詳細ページ。

**パスパラメータ**: `word_id` (int)

**レスポンス**: `words/detail.html`

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|

| `accuracy` | float \| None | 正解率（%）。未テストは None |
| `total_answers` | int | 総回答数 |

---

## クイズ (`/quiz`)

### `GET /quiz`

クイズ開始ページ。

**レスポンス**: `quiz/start.html`

---

### `POST /quiz/start`

クイズセッションを開始。

**ビジネスロジック**:
1. 優先度ロジックで `QUIZ_QUESTION_COUNT` 件の単語を選択
2. `QuizSession` 作成
3. `QuizSessionWord` を order 付きで一括作成
4. 最初の問題へリダイレクト

**レスポンス**: `/quiz/{session_id}` へリダイレクト

---

### `GET /quiz/{session_id}`

クイズ問題表示。

**パスパラメータ**: `session_id` (int)

**レスポンス**: `quiz/question.html`

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `session` | QuizSession | セッション情報 |
| `current_word` | Word | 現在の問題単語 |
| `progress` | dict | `{current, total}` |

---

### `POST /quiz/{session_id}/answer`

回答を送信。

**リクエスト**: `multipart/form-data`

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `word_id` | int | 回答した単語 ID |
| `is_correct` | str | `"true"` / `"false"` |

**ビジネスロジック**:
- `QuizAnswer` を記録
- `QuizSessionWord.is_answered = True`
- 全問終了時: `QuizSession.completed_at` 設定 + `StudyRecord` 更新

**レスポンス**: 次の問題 or `/quiz/{session_id}/result` へリダイレクト

---

### `GET /quiz/{session_id}/result`

クイズ結果ページ。

**レスポンス**: `quiz/result.html`

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `session` | QuizSession | セッション情報 |
| `correct_count` | int | 正解数 |
| `total_count` | int | 総問題数 |
| `incorrect_words` | list[Word] | 不正解単語リスト |

## AI 連携 (`/api/ai`)

AJAX エンドポイント。レスポンスは HTML フラグメント。

### `POST /api/ai/generate`

単語情報を AI で自動生成。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `word` | ✓ | 生成対象の単語 |

**レスポンス（成功時）**: `words/partials/ai_result.html` フラグメント（HTTP 200）

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `result` | AIGenerateResponse | 生成結果 |

**レスポンス（失敗時）**: `words/partials/ai_error.html` フラグメント

| ステータスコード | 状況 | テンプレート変数 |
|-----------------|------|-----------------|
| 429 | レート制限・クォータ超過 | `error`（メッセージ）, `retry_after_seconds`（再試行までの待機秒数、不明な場合あり） |
| 500 | その他の API 呼び出し失敗・レスポンス解析失敗 | `error`（メッセージ） |

---

### `POST /api/spell-check`

スペルチェック・重複チェック。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `word` | ✓ | チェック対象の単語 |

**レスポンス**: `ai/spell_check_result.html` フラグメント

| テンプレート変数 | 型 | 説明 |
|----------------|-----|------|
| `is_correct` | bool | スペルが正しいか |
| `suggestions` | list[str] | 修正候補 |
| `is_duplicate` | bool | 既存単語に重複があるか |

## インポート/エクスポート (`/export`)

### `GET /export/download/json`

全単語を JSON でダウンロード。

**レスポンス**: `Content-Disposition: attachment; filename="words_YYYYMMDD.json"`

**JSON 構造**:
```json
[
  {
    "word": "example",
    "reading": "/ɪɡˈzæmpəl/",
    "meaning": "例",
    "part_of_speech": "名詞",
    "example_sentences": [
      {"sentence_en": "...", "sentence_ja": "...", "order": 0, "label": null}
    ],
    "sources": [
      {"source_type": "book", "title": "...", "url": null, "page_number": null, "detail": null}
    ]
  }
]
```

---

### `GET /export/download/csv`

全単語を CSV でダウンロード。

**レスポンス**: `Content-Disposition: attachment; filename="words_YYYYMMDD.csv"`

**CSV カラム（13列）**:

| カラム名 | 説明 |
|---------|------|
| word | 単語 |
| reading | 読み |
| meaning | 意味 |
| part_of_speech | 品詞 |
| example_en_1 | 英語例文1 |
| example_ja_1 | 日本語訳1 |
| example_en_2 | 英語例文2 |
| example_ja_2 | 日本語訳2 |
| source_type | 出典種別 |
| source_title | 出典タイトル |
| source_url | URL |
| source_page | ページ番号 |
| source_detail | 詳細 |

---

### `POST /export/import`

ファイルから単語を一括インポート。

**リクエスト**: `multipart/form-data`

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `file` | ✓ | `.json` または `.csv` ファイル |

**レスポンス**: `/settings` へリダイレクト（フラッシュメッセージ付き）

**インポート結果**:
- `imported`: 登録件数
- `skipped`: 重複スキップ件数
- `errors`: エラー件数

## Pydantic スキーマ一覧

### AIGenerateResponse

```python
class ExampleSentence(BaseModel):
    sentence_en: str
    sentence_ja: str

class WordMeaning(BaseModel):
    brand: str       # 品詞
    meaning: str
    examples: list[ExampleSentence]

class AIGenerateResponse(BaseModel):
    reading: str
    word_meanings: list[WordMeaning]
```

```python
class ImportResult(BaseModel):
```
