# server_app 作成したい, 修正したい機能一覧

- [x] 3択テスト
    - [x] 一部の問題で答えを問う箇所が空欄にならない時がある
        - [x] 恐らく過去形など単語の形が変わると空欄にできないように見える
            - 対応済み: `_blank_word_in_sentence` で不規則動詞テーブル・規則変化（過去形・複数形・進行形など）の活用形候補も空欄化の対象にした。テーブルにない不規則動詞・特殊な活用形は依然対応できない場合がある（`docs/server_app/設計書.md` の「既知の制約」参照）。
    - [x] 他の選択肢でも意味が通ってしまうことがある
        - [x] どうすればいいか解決策を考えてください。
            - 対応済み: 誤答選択肢の類似度スコアに意味の重複度ペナルティを追加し、綴りが似ていても意味がほぼ同じ（類義語）候補は順位を下げるようにした（`similarity_service.py` の `_similarity_score`）。ただし汎用的な例文（例: "I saw a ___ yesterday."）では同じ品詞ならどの単語を入れても文として成立してしまう構造的な限界があり、これは意味の重複度だけでは解消できない。より厳密に解決するには、例文ごとに AI が文脈適合性を判定して誤答選択肢を選ぶ仕組み（単語登録時の AI 呼び出し回数増・データモデル変更が必要）が必要になるため、別途要望があれば検討する。
