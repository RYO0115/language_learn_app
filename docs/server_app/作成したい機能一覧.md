# server_app 作成したい, 修正したい機能一覧

- [x] 単語帳
    - [x] 単語検索機能
        - [x] 連続で検索すると検索できないことがある
            - 対応済み: 原因は検索語の末尾に付く空白・ゼロ幅文字（iPhone のキーボードが付与する `U+200B` 等。`str.strip()` では除去されない）で `ilike` の部分一致が外れ、結果0件→新規追加画面へリダイレクトされていたこと。`list_words` / 一覧ページ（`word_list_page`）で検索語を `normalize_word_text()`（前後空白除去・連続空白の畳み込み・ゼロ幅／不可視文字除去）で正規化してから照合するようにし、不可視文字の有無で検索が失敗しないようにした。
    - [x] 新規単語登録
        - [x] iPhoneで入力すると末尾にスペースが自動で追加されてしまう。その際にスペース有無で重複登録判定が別扱いになってしまう
            - 対応済み: 単語テキスト用の正規化関数 `normalize_word_text()` を `features/words/service.py` に追加し、登録（`create_word`）・テキスト照合（`get_word_by_text`）・重複/スペルチェック（`POST /api/spell-check`）・インポート（`features/export/service.py`）の全経路で適用。通常の空白に加え、`str.strip()` で除去できないゼロ幅・不可視文字（ZERO WIDTH SPACE `U+200B`・BOM `U+FEFF`・WORD JOINER `U+2060`・SOFT HYPHEN `U+00AD` など）も除去するため、末尾スペース・ゼロ幅文字の有無で同じ単語が別単語として重複登録されることがなくなった。ユニットテスト `tests/unit/test_word_normalization.py` を追加。
