## 単語管理 (words)

| # | 機能 | 詳細 |
|---|------|------|
| W-1 | 単語一覧表示 | ソート・フリーワード検索対応（検索語は前後の空白・ゼロ幅文字を正規化してから照合するため、iPhone 等が末尾に付与する不可視文字で検索が 0 件になることはない） |
| W-2 | 単語追加 | フォームからの手動入力 |
| W-3 | 単語詳細表示 | 精度統計（正解率）表示含む |
| W-4 | 単語編集 | 単語・読み・意味・品詞・例文・出典の更新 |
| W-5 | 単語削除（単体） | 1件削除 |
| W-6 | 単語削除（一括） | チェックボックス選択による複数削除 |
| W-7 | 重複チェック | 大文字小文字を区別しない重複防止。単語テキストは登録・照合時に正規化（前後の空白除去・連続空白の畳み込み・ゼロ幅／不可視文字の除去）するため、iPhone 等が末尾に付与する空白・ゼロ幅文字の有無で同じ単語が別扱いになり重複登録されることはない |
| W-8 | 出典管理 | 書籍・Web・動画・その他のソース情報保存 |
| W-9 | 例文管理 | 複数品詞対応・順序・ラベル付き例文 |
| W-10 | 一覧ソート | 登録日降順/昇順・ABC順・正解率昇順 |

## クイズ (quiz)

クイズには2種類のタイプ（`quiz_type`）があり、機能によって両テスト共通のものと、片方のテストにのみ存在するものがある。

| quiz_type | 概要 |
|-----------|------|
| `meaning`（デフォルト） | 単語を見て「覚えている/覚えていない」を自己判定する意味確認テスト |
| `fill_blank` | 例文中の対象単語を空欄にし、似ている単語2件を含む3択から正解を選ぶテスト（アンロック条件あり） |

### 両テスト共通

| # | 機能 | 詳細 |
|---|------|------|
| Q-1 | クイズ開始 | 優先度ベースで問題語彙を選択（`fill_blank` はアンロック済みかつ出題可能な単語のみが対象） |
| Q-2 | 結果表示 | セッション正解率・不正解語一覧 |
| Q-3 | 優先度選択ロジック | 未テスト語 → 未出題期間優先スロット → 低正解率語 → その他 の順で選択 |
| Q-4 | 学習記録更新 | クイズ完了時にストリーク記録を更新 |
| Q-5 | 未出題期間ベースの再出題 | 正答率が高い単語でも、残りスロットの一部（最大10%、最低1件）は最後に出題してから最も時間が経過している単語を正答率に関わらず優先的に再出題する（Q-3 の一部） |

### `meaning`（意味確認テスト）固有

| # | 機能 | 詳細 |
|---|------|------|
| Q-6 | 問題表示 | 単語を1問ずつ順番に表示 |
| Q-7 | 回答記録 | 「覚えている/覚えていない」の2択 |

### `fill_blank`（例文穴埋め3択テスト）固有

| # | 機能 | 詳細 |
|---|------|------|
| Q-8 | 例文穴埋め3択テスト | 単語の例文中の対象単語を空欄にし、似ている単語2件を含む3択から正解を選ぶ。原形に加えて lemminflect（形態素解析ライブラリ）による活用形（過去形・複数形・進行形・比較変化など、不規則変化を含む）にも対応して空欄化する |
| Q-9 | アンロック | 同じ品詞・例文付きの単語が3件以上登録されるとアンロックされる（未達の場合はトップ画面で開始ボタンを非表示） |
| Q-10 | 類似単語の事前計算 | 単語の作成・更新（品詞変更時は新旧両方）・削除のたびに、同じ品詞グループ内で類似度（先頭文字列の共通プレフィックス長・単語長の差・意味の重複度ペナルティ）を再計算し `word_similarities` に事前登録。意味がほぼ同じ（類義語）候補は誤答選択肢として不適切になりやすいため順位を下げる。出題時はここからランダムに誤答選択肢2件を抽出するため探索コストを抑える |
| Q-11 | 回答フィードバック | 回答後、例文の日本語訳と各選択肢（自分の選択・正解）の意味を表示する |

## AI連携 (ai)

| # | 機能 | 詳細 |
|---|------|------|
| A-1 | 単語情報自動生成 | 単語を入力すると読み・意味・例文を自動生成 |
| A-2 | スペルチェック | スペルミス検出・修正候補提示 |
| A-3 | Claude 連携 | Anthropic claude-haiku-4-5-20251001 使用 |
| A-4 | Gemini 連携 | Google gemini-2.0-flash 使用（切替可能） |
| A-5 | プロバイダ切替 | 環境変数 `AI_PROVIDER` で切替 |
| A-6 | レート制限ハンドリング | クォータ超過（429）を専用に検知し、再試行待機秒数を表示。生成ボタンはリクエスト中＋完了後15秒間操作不可、生成済み内容がある場合は再生成前に確認ポップアップを表示 |
| A-7 | Stub プロバイダ（テスト専用） | `AI_PROVIDER=stub` で実 API を呼ばず固定データを返す。`AI_STUB_FORCE_RATE_LIMIT=1` でレート制限を強制発生させ、UI テストを決定的に実行できる |

| # | 機能 | 詳細 |
|---|------|------|
| E-1 | JSON エクスポート | 全単語データを JSON ファイルでダウンロード |

## テスト (tests/ui, tests/unit)

| # | 機能 | 詳細 |
|---|------|------|
| T-1 | ブラウザ回帰テスト | Playwright for Python + pytest-playwright で主要ページ・フローを検証（`tests/ui/`） |
| T-2 | テスト用ライブサーバー | `tests/ui/conftest.py` が uvicorn をサブプロセス起動し、テスト用 SQLite DB と Stub AI プロバイダーで動作 |
| T-3 | ユニットテスト | サービス層のロジック（クイズ出題優先度など）を in-memory SQLite で直接検証（`tests/unit/`） |
| T-4 | CI 連携 | `.github/workflows/server_app_test.yml` で `server_app/**` 変更時に自動実行（unit + UI） |
| T-5 | 静的解析（lint） | ruff による静的解析を `.github/workflows/server_app_lint.yml` で `server_app/**` 変更時に自動実行。main へのマージはこのチェックの成功が必須（ブランチ保護） |
