# 開発仕様書

## ゴール

現在Pythonで作成している単語帳アプリをスマートフォンで動くアプリに作り直してください。

まずはiPhoneで動くことを目標にしてください。その後Androidへ移植します。

## 制約

実装するプログラミング言語はiOS, Androidの両方で動くものにしてください。

現在のPythonの環境はPythonアプリとして別ディレクトリに移動し、スマートフォンアプリはスマートフォンアプリとしてまた別のディレクトリに構築してください。

AI生成機能以外、スマートフォンのローカルで全て動作させてください。

機能の一覧を作成してください。

作成した機能の一覧をもとにリグレッションテストを作成し、機能を追加する時とPR提出時に実行されるようにしてください。

コーディング内容が重複しないようにしてください。

機能ごとにクラス化し、ディレクトリも分けるようにしてください。

iOSとAndroidで共有しやすい言語でアプリを開発してください。

ゆくゆくはアプリストアで無料公開し、広告収入が得られるようにしてください。

ローカルの容量は100MBまでにしてください。

単語帳のデータベースが100MBを超える場合は、警告が出るようにしてください。そこでokを選択されたらそのままデータベースを更新してください。

アプリの中にデータベースサイズの上限値を変更できる機能も追加してください。

分からないところは都度質問してください。
