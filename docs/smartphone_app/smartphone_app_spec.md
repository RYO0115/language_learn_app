## 1. プロジェクト概要

現行の Python 製単語帳 Web アプリをスマートフォンネイティブアプリとして再構築する。
iOS を先行リリースし、その後 Android へ展開する。
将来的にはアプリストア（App Store / Google Play）で無料公開し、広告収入を得ることを目標とする。

## 3. 機能一覧

### 3.1 単語管理機能

| ID | 機能名 | 説明 |
|----|--------|------|
| W-01 | 単語追加（手動） | 英単語・読み・意味・品詞を手動入力して登録する |
| W-02 | 単語編集 | 登録済み単語の各フィールドを編集する |
| W-03 | 単語削除 | 単語を削除する（例文・出典も連動削除） |
| W-04 | 単語一覧表示 | 登録済み単語をリスト表示する（検索・フィルター付き） |
| W-05 | 単語詳細表示 | 単語の全情報（意味・品詞・例文・出典）を表示する |
| W-06 | 重複チェック | 同一単語の二重登録を防ぎ、スペル候補を提示する |
| W-07 | 例文管理 | 1単語に複数の例文（英文＋和訳）を登録・編集・削除する |
| W-08 | 出典管理 | 単語を見かけた出典（書籍・URL・動画など）を登録する |

### 3.2 AI 生成機能

| ID | 機能名 | 説明 |
|----|--------|------|
| A-01 | 単語情報の自動生成 | 英単語を入力すると、意味・品詞・発音記号・例文を AI が生成する |
| A-02 | プロバイダー切り替え | Claude / Gemini を設定画面から切り替えられる |
| A-03 | API キー管理 | 各プロバイダーの API キーをアプリ内に安全に保存する |
| A-04 | API キー初回設定画面 | 起動時に API キーが未設定の場合、設定画面を強制表示する。入力欄の下に取得手順を記載する |

> AI 機能のみネットワーク通信が必要。その他はすべてオフライン動作。
> API キーはユーザー自身が取得する（アプリ側のプロキシなし）。

### 3.3 クイズ機能

| ID | 機能名 | 説明 |
|----|--------|------|
| Q-01 | クイズ開始 | 設定した出題数でクイズセッションを開始する |
| Q-02 | 問題出題 | 単語を表示し、意味を自己採点（知っていた / 知らなかった）する |
| Q-03 | 優先度制御 | 未テスト単語 → 低正答率単語 → それ以外の順で優先出題する |
| Q-04 | 回答記録 | 正解・不正解を記録する |
| Q-05 | 結果表示 | セッション終了後に正答率・不正解単語一覧を表示する |

### 3.4 学習記録機能（ストリーク）

| ID | 機能名 | 説明 |
|----|--------|------|
| S-01 | 学習日記録 | クイズ完了時に学習日として記録する |
| S-02 | カレンダー表示 | 月単位のカレンダーで学習日を可視化する |
| S-03 | 連続学習日数表示 | 現在の連続学習日数（ストリーク）を表示する |

### 3.5 エクスポート / インポート機能

| ID | 機能名 | 説明 |
|----|--------|------|
| E-01 | JSON エクスポート | 全単語データを JSON 形式でエクスポートする |
| E-02 | CSV エクスポート | 全単語データを CSV 形式でエクスポートする |
| E-03 | JSON インポート | JSON ファイルから単語データをインポートする（重複はスキップ） |
| E-04 | CSV インポート | CSV ファイルから単語データをインポートする（重複はスキップ） |

### 3.6 ストレージ管理機能

| ID | 機能名 | 説明 |
|----|--------|------|
| ST-01 | DB 容量監視 | アプリ起動時・単語登録時にデータベースの容量を確認する |
| ST-02 | 容量超過警告 | DB サイズが上限値を超えた場合に警告ダイアログを表示する |
| ST-03 | 警告後の継続 | ユーザーが「OK」を選択した場合はそのまま登録を続行する |
| ST-04 | 上限値設定 | DB サイズの上限値を設定画面から変更できる（デフォルト: 100 MB） |

### 3.7 設定機能

| ID | 機能名 | 説明 |
|----|--------|------|
| CFG-01 | AI プロバイダー選択 | Claude / Gemini を切り替える |
| CFG-02 | API キー設定 | 各プロバイダーの API キーを入力・保存する |
| CFG-03 | クイズ出題数設定 | 1セッションあたりの出題数を設定する（デフォルト: 20問） |
| CFG-04 | DB 上限値設定 | ストレージ警告の閾値を MB 単位で設定する（デフォルト: 100 MB） |

## 4. 非機能要件

### 4.1 パフォーマンス

- 単語一覧表示: 1,000件を 1秒以内に表示
- クイズ開始: 2秒以内
- AI 生成: ネットワーク応答依存（タイムアウト: 30秒）

### 4.2 ストレージ

- アプリ本体（コード・アセット）: 100 MB 以内
- データベース（ユーザーデータ）: デフォルト上限 100 MB（ユーザー変更可）
- DB が上限を超えた場合、警告ダイアログを表示する。「OK」選択で登録継続。

### 4.3 オフライン動作

- AI 生成機能を除くすべての機能はオフラインで動作すること

### 4.4 セキュリティ

- API キーはデバイスのキーチェーン（iOS: Keychain / Android: Keystore）に保存する
- データベースは端末ローカルに保存し、外部送信しない

### 4.5 テスト

- 機能一覧をもとにリグレッションテストを整備する
- 機能追加時と PR 提出時に CI でテストを自動実行する
- テストカバレッジ: ビジネスロジック層 80% 以上を目標

### 4.6 コード品質

- コーディング内容の重複を排除する（DRY 原則）
- 機能ごとにクラス化し、ディレクトリを分ける（Feature-first 構造）

### 4.7 多言語対応

- 初期リリースは日本語のみ
- ゆくゆくは他言語への対応を予定するため、UI テキストはすべてアプリ内文字列リソース（ARB ファイル）で管理し、ハードコードしない

### 4.8 バックアップ拡張性

- Phase 1 リリース時点では iCloud / Google Drive バックアップは実装しない
- ただし、将来の追加時に変更が最小限になるよう、バックアップ処理を抽象レイヤーとして設計に組み込む（詳細は設計書参照）

## 7. データモデル（論理設計）

### words（単語）
| カラム | 型 | 説明 |
|-------|----|------|
| id | INTEGER PK | 主キー |
| word | TEXT UNIQUE | 英単語 |
| reading | TEXT? | 発音記号 |
| meaning | TEXT | 日本語の意味 |
| part_of_speech | TEXT? | 品詞 |
| created_at | INTEGER | 登録日時（Unix timestamp） |
| updated_at | INTEGER | 更新日時（Unix timestamp） |

### example_sentences（例文）
| カラム | 型 | 説明 |
|-------|----|------|
| id | INTEGER PK | 主キー |
| word_id | INTEGER FK | words.id |
| sentence_en | TEXT | 英語例文 |
| sentence_ja | TEXT | 日本語訳 |
| order | INTEGER | 表示順 |
| label | TEXT? | 品詞ラベル |

### word_sources（出典）
| カラム | 型 | 説明 |
|-------|----|------|
| id | INTEGER PK | 主キー |
| word_id | INTEGER FK | words.id |
| source_type | TEXT | book / website / video / other |
| title | TEXT? | 書籍名・サイト名など |
| url | TEXT? | URL |
| page_number | TEXT? | ページ・章番号 |
| detail | TEXT? | その他詳細 |
| created_at | INTEGER | 登録日時 |

### quiz_sessions（クイズセッション）
| カラム | 型 | 説明 |
|-------|----|------|
| id | INTEGER PK | 主キー |
| started_at | INTEGER | 開始日時 |
| completed_at | INTEGER? | 完了日時 |

### quiz_answers（クイズ回答）
| カラム | 型 | 説明 |
|-------|----|------|
| id | INTEGER PK | 主キー |
| session_id | INTEGER FK | quiz_sessions.id |
| word_id | INTEGER FK | words.id |
| is_correct | INTEGER | 1=正解 / 0=不正解 |
| answered_at | INTEGER | 回答日時 |

### study_records（学習記録）
| カラム | 型 | 説明 |
|-------|----|------|
| id | INTEGER PK | 主キー |
| study_date | TEXT UNIQUE | 学習日（YYYY-MM-DD） |
| words_studied | INTEGER | 学習単語数 |
| quiz_completed | INTEGER | クイズ完了回数 |

## 8. API キー取得手順（A-04 画面内に表示する内容）

### Google Gemini（推奨・無料・クレジットカード不要）

**無料枠の制限:** 1,500 リクエスト/日・30 リクエスト/分。単語 1 件の生成 = 1 リクエストのため、個人利用には十分。

1. `https://aistudio.google.com/apikey` にアクセスし、Google アカウントでログインする
2. 「API キーを作成」ボタンを押す
3. 生成されたキーをコピーしてアプリの入力欄に貼り付ける

### Anthropic Claude（有料プランが必要）

1. `https://console.anthropic.com/` にアクセスし、アカウントを作成する
2. 「API Keys」メニューからキーを発行する
3. 生成されたキーをコピーしてアプリの入力欄に貼り付ける
